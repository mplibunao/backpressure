# @mplibunao/oxlint-standards

Opinionated oxlint presets for MP's code-quality backpressure package.

Status: package skeleton only. The baseline exports an empty plugin so workspace build and package checks can run before rule work.

## Attribution

Future Effect rules are planned as derived work from `@catenarycloud/linteffect`, the MIT-licensed GritQL rule pack by Roman Naumenko. The GritQL tooling is not copied into this package.

# Mutation reports

This directory holds dated outputs from mutation-testing sweeps.

Use this area for run-specific evidence such as survivor summaries, follow-up notes, and sweep results. Keep durable workflow guidance in `docs/references/mutation-testing.md` so `docs/references/` stays stable and does not accumulate per-run reports.

Naming convention:

```text
YYYY-MM-DD-<short-scope>.md
```

Example: `2026-05-31-v0-sweep.md`.
